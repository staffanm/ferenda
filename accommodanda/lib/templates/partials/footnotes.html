{%- macro footnote_list(footnotes) -%} {#- The endnote list at the foot of a document. `footnotes` are {n, html, backref}: `n` the marker the source printed, `html` the note's rendered runs, `backref` true where the body carries a matching inline marker to return to (dv's "[N]"), which is also what makes `n` a document-unique id. A letterhead PDF's notes carry no such marker -- poppler renders the superscript glued into the prose -- and their printed numbers restart per page and per part document, so those list with the marker shown as a label and no id: an id that repeats and anchors nothing is worse than none. -#}

Fotnoter

    {%- for fn in footnotes -%} {%- if fn.backref -%}
  1. {{ fn.html }} ↩
    2. {%- else -%}
  2. {% if fn.n %}{{ fn.n }} {% endif %}{{ fn.html }}
    3. {%- endif -%} {%- endfor -%}
{%- endmacro -%}
