{#- The screen a reader waits on while a PDF export renders (api/pdfjob.py). It exists because the alternative was a blank tab: the dialog used to open a window with no address and write "Skapar PDF …" into it, which left the reader on a document they could not reload, share or keep, and which said nothing about how long the wait would be. The page starts the job itself. That way the tab can be opened inside the click that asked for it -- a popup blocker allows nothing opened a minute later -- while the render still only begins once, since the server joins identical jobs.
